# LinguaCards (Eindproject)

Monolingual flashcard web app.

## Tech
- Backend: Java 17, Spring Boot, Spring Security, Spring Data JPA, MySQL
- Frontend: Angular

## Repo structure
- `backend/` Spring Boot REST API
- `frontend/` Angular SPA

## Run (local)
### Backend
Open `backend/` in IntelliJ and run the Spring Boot application.
